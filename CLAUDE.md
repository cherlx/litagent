# Правила общения

- Общаться на русском языке.
- Отвечать по делу, без многословности. Подробные пояснения — только по явному запросу.

# Рабочий процесс

- Правки — через фича-ветки (не напрямую в `main`), затем слияние.
- Версию приложения повышать по semver, в соответствии с объёмом изменений: патч —
  багфиксы, минор — новая функциональность без слома совместимости, мажор — ломающие
  изменения.
- При изменениях, которые затрагивают пользователя, актуализировать README, Wiki и
  начальный экран приложения (стартовую подсказку в интерфейсе) — не оставлять их
  рассинхронизированными с кодом.
